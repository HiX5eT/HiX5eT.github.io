# 👾 HTML Canavarı: Ultimate Edition

Saf HTML5 Canvas, CSS ve JavaScript kullanılarak geliştirilmiş, retro tarzı aksiyon dolu bir **Boss Savaşı ve Nişancı (Shoot 'em up)** oyunu.

## 🚀 Oyun Özellikleri
- 🕹️ **Çift Kontrol Desteği:** İster **PC (Klavye)** ister **Mobil (Dokunmatik Joystick)** ile oynayın.
- 🛒 **Dükkan ve Geliştirmeler:** Kazandığınız altınlarla hızınızı artırın, ateş hızını yükseltin, üçlü ateş açın, can yenileyin veya bomba satın alın!
- ⚡ **Dinamik Fazlar:** Boss'un canı azaldıkça saldırma hızı ve mermi sayısı artar.
- 🔊 **Web Audio API:** Harici ses dosyasına ihtiyaç duymadan saf kodla üretilen retro ses efektleri.

## 🕹️ Nasıl Oynanır?

### 💻 PC / Klavye Kontrolleri
- **Yön Tuşları** veya **W, A, S, D:** Gemiyi hareket ettir.
- **Otomatik Ateş:** Gemi otomatik olarak ateş eder.

### 📱 Mobil Kontroller
- Sol alttaki **Joystick** ile hareket edin, sağdaki **ATEŞ** butonuna basılı tutarak ateş edin.

## 🛠️ Kullanılan Teknolojiler
- **HTML5 Canvas:** Yüksek performanslı 2D grafik çizimi.
- **CSS3:** Retro arayüz, dükkan paneli ve can barları tasarımı.
- **Vanilla JavaScript:** Oyun döngüsü, çarpışma algoritmaları ve nesne yönelimli yapılar.
