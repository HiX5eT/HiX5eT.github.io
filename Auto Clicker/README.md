# 🖱️ Python Auto Clicker (Executable Edition)

Python ve otomasyon kütüphaneleri kullanılarak geliştirilmiş; hızlı, pratik ve kullanıcı dostu bir otomatik tıklama (Auto Clicker) aracı.

## 🚀 Özellikler

- ⚡ **Yüksek Performans:** İstediğiniz milisaniye aralığında seri ve kesintisiz tıklama.
- 🎯 **Kolay Kullanım:** Arka planda yorulmadan çalışan hafif mimari.
- 📦 **Tek Dosya Kolaylığı:** Ekstra Python kurulumu gerektirmeyen, doğrudan `.exe` üzerinden çalıştırılabilen yapı.

## 🛠️ Kullanılan Teknolojiler

- **Python:** Çekirdek otomasyon mantığı.
- **PyAutoGUI / Keyboard:** Fare ve klavye olaylarını yakalama ve tetikleme.
- **PyInstaller:** Kodun bağımsız bir `.exe` dosyasına dönüştürülmesi.

## 💻 Nasıl Kullanılır?

1. Hazırlanan `AutoClicker.exe` dosyasını indirin.
2. Çift tıklayarak uygulamayı çalıştırın.
3. Belirlenen kısayollarla tıklamayı başlatıp durdurun.
